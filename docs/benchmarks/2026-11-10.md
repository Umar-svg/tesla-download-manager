# Benchmarks 2026-11-10

Generated by `tools/bench/run_bench.py`. Every row is measured; every download's SHA-256 was verified against the server (and, for Tesla DM, re-hashed independently from disk).

## Setup

- os: Windows-11-10.0.26200-SP0
- python: 3.15.2
- logical_cpus: 12
- cpu: 13th Gen Intel(R) Core(TM) i7-1355U
- cores: 10
- ram_gib: 15.7
- disk: NVMe BC901 NVMe SK hynix 1024GB (SSD)
- curl: curl 8.21.0 (Windows) libcurl/8.21.0 Schannel zlib/1.3.2 WinIDN WinLDAP
- client and Python probe server on the same machine over loopback (127.0.0.1)
- repetitions per variant: 3 (median shown; min/max in brackets)

Tesla DM times run from adding the URLs until every download is Completed, so they include the engine's own finalize step (rename + SHA-256 of the file). curl times are the whole process run.
